## About this site

This site is hosted on GitHub Pages. GitHub collects visitor data (including IP
addresses) as the hosting provider, as described in the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Beyond that, this site does not track you: there are no analytics, no advertising,
and no tracking cookies. The only thing stored in your browser is a small local
entry that remembers your theme and contrast preference, and it never leaves your
device.

For privacy and support questions about a specific app, see that app's own
documents linked from the [home page]({{ '/' | relative_url }}). For anything
about this site itself, email [{{ site.contact_email }}](mailto:{{ site.contact_email }}).
